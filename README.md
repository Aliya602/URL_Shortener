## URL_Shortener
Two Python URL shorteners using the TinyUrl API - from simple to advanced

## API USED
TinyURL API (https://tinyurl.com/) - Free, no API key required

## Files
 File | Description |
| `url_shortener_simple.py` - Basic version (15 lines) - learn POST requests |
| `url_shortener_advanced.py`- Full-featured version - history, clipboard, menu |

## Features (Advanced)
- ✅ Shorten any URL using TinyURL API
- ✅ Auto-copy shortened URL to clipboard
- ✅ URL history with timestamps
- ✅ Save/load history to JSON file
- ✅ URL validation (auto-adds http:// /https://)
- ✅ Error handling for network issues or any sort of issues
- ✅ Clear history option

## How to run 🔃

pip install -r requirements.txt

Run simple version
python url_shortener_simple.py (terminal)

Run advanced version
python url_shortener_advanced.py(terminal)
